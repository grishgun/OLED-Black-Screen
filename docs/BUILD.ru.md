# Сборка OLED Black Screen — русский

[English](BUILD.en.md) | **Русский**

## Что потребуется

- Компьютер или виртуальная машина с Windows 11 x64.
- Visual Studio Build Tools: компонент **MSVC v143 или новее** и **Windows SDK**.
- Консоль **x64 Native Tools Command Prompt for Visual Studio**.

## Компиляция

В каталоге проекта выполните:

```cmd
Build-Windows.cmd
```

Скрипт компилирует `OledBlackScreen.c`, создаёт ресурс из `OledBlackScreen.rc` с иконкой `icon.ico` и связывает итоговый `OledBlackScreen.exe` для Windows x64.

Программа использует стандартные системные библиотеки Windows, собственную точку входа и не требует C Runtime. Параметр `/NODEFAULTLIB` означает, что при добавлении функций стандартной библиотеки C в дальнейшем скрипт сборки может потребовать изменения.

## GitHub Actions и релиз

Файл автоматизации: `.github/workflows/release.yml`.

- При каждом push в `main` GitHub Actions собирает приложение и прикладывает артефакт **OLED-Black-Screen-Windows-x64** к запуску во вкладке **Actions**.
- Первая успешная сборка в `main` автоматически создаёт `v0.1.0-preview` (если релиза ещё нет). Для следующих релизов откройте **Actions → Windows build and release → Run workflow** и укажите версию, например `v0.1.0-preview`.
- GitHub заново соберёт EXE и приложит `OledBlackScreen.exe` к **pre-release**. Требуется включённый GitHub Actions и разрешение `contents: write` для `GITHUB_TOKEN`.

Успешная компиляция ещё не означает, что программу проверили в реальной Windows.

## Проверка перед публикацией

1. Запустите приложение, убедитесь в наличии значка и практически нулевой загрузке CPU в простое.
2. Включите автозапуск и проверьте его после нового входа в Windows.
3. Включите чёрный экран через трей и через классическое контекстное меню рабочего стола.
4. Проверьте все мониторы, включая вариант с включённым HDR.
5. Убедитесь, что движение указателя не выводит из режима, а клавиша, кнопка и колесо — выводят.
6. Проверьте обычную работу мыши и клавиатуры после закрытия экрана.
7. Выберите **Выход** и убедитесь, что значок и пункт меню исчезли.
8. Проверьте поведение после перезапуска Проводника и смены конфигурации дисплеев.

Работа на защищённом рабочем столе Windows, экране блокировки, в эксклюзивных полноэкранных приложениях, через RDP и при конфликте с другими оверлеями не гарантируется.
