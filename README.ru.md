# OLED Black Screen

[English](README.md) | **Русский**

**OLED Black Screen** — небольшая нативная утилита для Windows, которая выводит чистый чёрный цвет `#000000` на все мониторы, не выключая их. Удобно включить перед тем, как отойти от компьютера, чтобы на OLED-экране не оставались статичные элементы рабочего стола.

> **Предварительная версия (v0.1.0-preview).** Исходный код уже собран в EXE для x64, но работа приложения **ещё не проверена в реальном сеансе Windows**. EXE не подписан цифровой подписью. Рекомендуется сначала протестировать его на своём ПК.

## Возможности

- Полноэкранный чёрный цвет RGB `(0, 0, 0)` на всех подключённых мониторах.
- Левый клик по значку в трее включает чёрный экран; правый открывает меню.
- Пункт **Black screen** в контекстном меню рабочего стола, пока программа запущена. В Windows 11 он находится в **Показать дополнительные параметры**.
- Для выхода нажмите **любую клавишу, кнопку мыши или прокрутите колесо**. Простое движение мыши ничего не делает.
- Во время чёрного экрана Windows получает запрос не выключать дисплей (`SetThreadExecutionState`).
- Переключатель автозапуска с Windows для текущего пользователя.
- Без установщика, .NET, сетевых запросов, телеметрии и периодических фоновых проверок.
- Нативный Win32: перехватчики клавиатуры и мыши действуют только при включённом чёрном экране.

## Требования

- Windows 11 x64 (другие версии Windows пока не проверялись).
- Любой монитор; основной сценарий использования — OLED.
- Права администратора не требуются.

## Загрузка и установка

1. Откройте **Releases** этого репозитория и скачайте `OledBlackScreen.exe` из последней предварительной версии. Если релиз ещё не опубликован, используйте артефакт во вкладке **Actions** или [соберите исходники](docs/BUILD.ru.md).
2. Положите EXE в постоянную папку, например `C:\Tools\OLED-Black-Screen\`.
3. Запустите `OledBlackScreen.exe`. Значок появится в трее (при необходимости нажмите стрелку скрытых значков).
4. При желании включите пункт **Автозапуск с Windows** через ПКМ по значку в трее.

**Важно:** после настройки автозапуска не переносите и не переименовывайте EXE: Windows запоминает текущий путь к программе. SmartScreen или антивирус могут предупреждать о новом EXE без цифровой подписи. При желании проверьте исходники и соберите приложение самостоятельно.

## Управление

| Действие | Результат |
| --- | --- |
| Левый клик по значку в трее | Включить чёрный экран |
| Правый клик по значку в трее | Меню: Black screen, автозапуск, выход |
| ПКМ по пустому месту рабочего стола → Показать дополнительные параметры → Black screen | Включить чёрный экран |
| Любая клавиша клавиатуры | Выключить чёрный экран |
| Кнопка мыши или прокрутка колеса | Выключить чёрный экран |
| Только движение мыши | Чёрный экран остаётся |

Чёрная поверхность перекрывает весь *виртуальный рабочий стол* Windows, в том числе несколько мониторов. Яркость, цветовой профиль, HDR и режим питания экрана не меняются.

## Удаление

1. Нажмите ПКМ по значку в трее и отключите **Автозапуск с Windows**, если он был включён.
2. Выберите **Выход**. Программа уберёт пункт из контекстного меню рабочего стола.
3. Удалите EXE.

Если приложение было принудительно завершено или Windows внезапно выключилась, пункт меню может остаться. Удалите его командой в **cmd**, запущенной от того же пользователя:

```cmd
reg delete "HKCU\Software\Classes\DesktopBackground\Shell\OledBlackScreen" /f
```

При необходимости отдельно уберите запись автозапуска:

```cmd
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v OledBlackScreen /f
```

## Что важно для OLED

При отображении абсолютно чёрного цвета пиксели обычной OLED-матрицы не светятся. Однако утилита **не заменяет** встроенные механизмы ухода за панелью, компенсацию износа, штатную заставку или выключение монитора. Системные уведомления, защищённый рабочий стол и некоторые окна поверх всех остальных могут показываться над чёрным экраном. Монитор намеренно остаётся включённым.

## Конфиденциальность

Программа не использует интернет и не собирает данные пользователя. Только во время чёрного экрана она временно устанавливает низкоуровневые обработчики ввода, чтобы закрыть экран при нажатии клавиши, кнопки или прокрутке колеса мыши. Ввод нигде не записывается.

Исходники доступны для проверки: [сборка](docs/BUILD.ru.md), [вопросы и ответы](docs/FAQ.ru.md), [безопасность](SECURITY.md).

## Для разработчиков

Исходный код находится в [OledBlackScreen.c](OledBlackScreen.c); рядом лежат иконка и [Build-Windows.cmd](Build-Windows.cmd). GitHub Actions собирает EXE на Windows. После каждой отправки в `main` доступен артефакт сборки; первая успешная сборка ветки main автоматически публикует предварительный релиз v0.1.0-preview; следующие релизы можно запускать вручную.
