# Changelog / История изменений

## v0.1.0-preview — initial preview / первая предварительная версия

**English**
- Native Windows x64 tray application.
- Black fullscreen overlay covering the virtual desktop.
- Exit on keyboard, mouse button or wheel; ignore pointer movement.
- Classic desktop context menu command, optional launch at startup.
- Source code, build script, icon, MIT license, CI build and preview release workflow.
- Runtime testing on Windows: **pending**.

**Русский**
- Нативная программа для Windows x64 со значком в трее.
- Чёрный полноэкранный оверлей на весь виртуальный рабочий стол.
- Выход по клавиатуре, кнопке мыши или прокрутке; движение указателя игнорируется.
- Пункт классического контекстного меню рабочего стола, необязательный автозапуск.
- Исходники, скрипт сборки, иконка, лицензия MIT и GitHub Actions.
- Проверка работы в настоящем сеансе Windows: **ещё не проведена**.
